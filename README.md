# 🎯 AZ-900 Exam Information

| Information | Details |
|---|---|
| **Exam** | AZ-900: Microsoft Azure Fundamentals |
| **Certification** | Microsoft Certified: Azure Fundamentals |
| **Level** | Fundamentals / Beginner |
| **Passing Score** | **700 / 1000** |
| **Exam Language** | English and other supported languages |
| **Exam Delivery** | Pearson VUE / Microsoft exam delivery options |
| **Exam Type** | Computer-based certification exam |
| **Exam Duration** | Approximately **45 minutes for the exam portion** |

| **Certification** | Earned after successfully passing AZ-900 |

# 📝 AZ-900 Question Format

AZ-900 is a fundamentals-level certification exam.

You may encounter different question formats, including:

* Single-answer multiple choice
* Multiple-answer questions
* Matching
* Drag-and-drop style questions
* Scenario-based questions where applicable
* Other interactive question formats

> The exact question mix can change between exam versions.

### Important

Do **not** prepare by memorizing a fixed number of questions.

Instead, focus on understanding:

```text
Concept
   ↓
Azure Service
   ↓
Purpose
   ↓
Use Case
   ↓
Correct Service Selection
```

---

# 🎯 Passing Score

Microsoft uses a scaled scoring system.

### Passing score:

**700 / 1000**

This does **not** mean you simply need 70% of the questions correct.

For example:

```text
700 / 1000 = PASS
699 / 1000 = FAIL
```

Do not try to calculate the exact number of questions required to pass from the percentage alone.

The safest strategy is to aim for strong knowledge across **all three exam domains**.

---

# ⏱️ Exam Time

The actual exam portion is approximately:

**45 minutes**

However, your total appointment/seat time can be longer because it may include:

* Exam instructions
* Candidate agreement
* Tutorial/instructions
* Exam questions
* Optional comments/survey

Therefore:

```text
Seat Time
   ≠
Exam Question Time
```

Always check the current Microsoft exam information when booking your exam.

# 🔥 High-Value Exam Comparisons

| Topic                                 | Understand                                                 |
| ------------------------------------- | ---------------------------------------------------------- |
| CapEx vs OpEx                         | Up-front investment vs consumption-based spending          |
| IaaS vs PaaS vs SaaS                  | Different levels of provider/customer responsibility       |
| Public vs Private vs Hybrid           | Different cloud deployment models                          |
| Scalability vs Elasticity             | Ability to scale vs dynamic scaling                        |
| Region vs Availability Zone           | Geographic location vs isolated datacenter location        |
| Resource Group vs Subscription        | Resource container vs management/billing boundary          |
| RBAC vs Azure Policy                  | Access control vs governance                               |
| NSG vs Azure Firewall                 | Network filtering vs centralized firewall capabilities     |
| Load Balancer vs Application Gateway  | Network-level vs application-level traffic distribution    |
| VPN Gateway vs ExpressRoute           | Encrypted connection over internet vs private connectivity |
| Azure Monitor vs Service Health       | Resource monitoring vs Azure service status                |
| Pricing Calculator vs Cost Management | Estimate future costs vs analyze current spending          |
| VM vs App Service                     | Infrastructure control vs managed application platform     |
| App Service vs Functions              | Web application hosting vs serverless/event-driven compute |
| Blob vs Azure Files                   | Object storage vs managed file shares                      |

Practice:

* Select region

```text
VNet

├── WebSubnet
│
└── AppSubnet
```

Practice:

* Address spaces
* Subnets
* NSGs

* Private IP

---

## Lab 4 — Virtual Machine

Practice:

* Select region
* Select VM size
* Select OS
* Configure networking
* Configure authentication
* Review estimated cost

---

## Lab 5 — Azure CLI

```bash
az login
```

Create resource group:

```bash
az group create \
  --name az900-cli-rg \
  --location eastus
```

List resource groups:

```bash
az group list --output table
```

Delete the lab:

```bash
az group delete \
  --name az900-cli-rg \
  --yes
```
